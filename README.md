# 💬 Quote Fetching App

Get inspired — one quote at a time!  
**Get a quote from our quote fetching app**, a sleek and lightweight web application built with **HTML5**, **CSS3**, and **JavaScript (ES6)**.

---

## 🚀 Overview

This project fetches and displays random motivational or thought-provoking quotes from an external API.  
It’s a simple yet elegant web app that demonstrates clean UI design and smooth asynchronous JavaScript functionality.

---

## 🧠 Features

- ⚡ Fetches real-time quotes dynamically using an API  
- 💡 Modern ES6+ JavaScript practices (arrow functions, async/await, fetch API)  
- 🎨 Clean, responsive layout built with HTML5 and CSS3  
- 🔄 Option to generate a new quote with a single click  
- 🐦 Optional share button to tweet your favorite quote  

---

## 🧰 Technologies Used

| Technology | Purpose |
|-------------|----------|
| **HTML5** | Structure of the web app |
| **CSS3** | Styling and responsive layout |
| **JavaScript (ES6)** | Logic, interactivity, and API integration |

---

## 🧩 How It Works

1. The app sends a request to a public quotes API (like [Quotable.io](https://api.quotable.io) or another source).  
2. The API responds with a random quote and author data.  
3. The quote is displayed dynamically on the screen.  
4. Users can click a button to fetch a new random quote instantly.
